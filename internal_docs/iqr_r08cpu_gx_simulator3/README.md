This folder records local GX Simulator 3 validation results for the R08CPU
simulation endpoint.

- Simulator: GX Simulator 3

- Host: 127.0.0.1
- TCP port: 5511
- Primary manual profile used for command validation: 4E frame + iQR access profile
- Required GX Works3/GX Simulator 3 setting: `Enable/Disable Online Change: Enable All (SLMP)`
